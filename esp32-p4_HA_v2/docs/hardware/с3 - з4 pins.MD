# C3 ↔ P4: распиновка

Связь ESP32-C3 (Wi-Fi, ESP-Hosted) с ESP32-P4. Источник: `JC4880P443C_I_W.md` §4.5.

| Сигнал | P4 (JP1) | C3 | Направление |
|---|---|---|---|
| SPI CLK | GPIO32 | GPIO6 | P4 → C3 |
| SPI MOSI | GPIO28 | GPIO7 | P4 → C3 |
| SPI MISO | GPIO33 | GPIO5 | C3 → P4 |
| SPI CS | GPIO31 | GPIO10 | P4 → C3 |
| HANDSHAKE | GPIO49 | GPIO4 | C3 → P4 |
| DATA_READY | GPIO50 | GPIO3 | C3 → P4 |
| RESET (EN) | GPIO34 | EN / RST | P4 → C3 |
| GND | GND | GND | общий |
| Питание | 5V | 5V | лучше раздельно |

## При пайке и проверке

- **GND** между платами обязателен. Питание C3 лучше отдельное (с P4 делить только GND):
  просадки 5V при пере-энумерации P4 сбрасывают C3.
- На C3 не занимать **GPIO11–17** (SPI-flash). Выбранные 3/4/5/6/7/10 свободны, без
  strapping (2/8/9) и USB.
- **RESET обязателен**: P4 дёргает GPIO34 перед bring-up; без него C3 не отдаст caps
  (handshake) при позднем старте.
- SPI — **mode 3, 40 МГц**. В текущем `sdkconfig` P4 стоит диагностический mode 2 / 20 МГц
  (от тестов с ESP32) — перед работой с C3 вернуть на 3 / 40.
- Проводники минимальной длины; MISO/CLK — самые чувствительные.
