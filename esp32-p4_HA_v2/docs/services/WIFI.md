# Wi-Fi Service

Слой: **Services / Wi-Fi**. Карта системы — `../ARCHITECTURE.md`.
Документ описывает контракт и поведение; конкретная реализация — в коде.
Формы — `ha_model/ha_wifi.h`; разводка C3 — `../hardware/JC4880P443C_I_W.md` §4.5.

## 1. Роль

Единственный владелец Wi-Fi-радио. У P4 нет своего радио, встроенный C6 занят 802.15.4
(Zigbee/RCP), поэтому Wi-Fi живёт на **внешнем ESP32-C3** через `ESP-Hosted` (SPI).
Сервис поднимает стек, сканирует, подключается и держит provisioning; состояние и
результаты скана отдаёт через Domain, запросы принимает командами.

## 2. Данные (Domain)

| Сущность | Что | Backing |
|---|---|---|
| `HA_ENTITY_WIFI_STATUS` | `state` (`ha_wifi_state_t`), `connected`, `ssid`, `rssi` | RAM |
| `HA_ENTITY_WIFI_SCAN` | результат последнего скана (`count` + `aps[]`) | RAM |
| `HA_ENTITY_WIFI_KNOWN` | известные точки (`ssid` + `password`) | RAM\|FLASH |

`wifi_scan` — рабочие данные: сервис очищает её, когда подключение состоялось.
`wifi_known` — персистентна: автоподключение при старте.

## 3. Команды

```text
HA_CMD_WIFI_SCAN     → асинхронный скан; результат кладётся в HA_ENTITY_WIFI_SCAN
HA_CMD_WIFI_CONNECT  → args ha_wifi_connect_args_t; сохранить в известные + подключиться
```

Исполнители **короткие**: копируют запрос в очередь задачи сервиса и возвращаются.
Радио-вызовы (`esp_wifi_*`) идут в контексте задачи сервиса, не в контексте вызывающего
(`../domain/COMMANDS.md`).

## 4. Автоподключение при старте

Если известные точки есть — скан и выбор **известной с самым сильным сигналом**
(`wifi_select_known`, host-тест `wifi/tests/test_wifi_select.c`), затем подключение.
Если нет — состояние `IDLE`, сети нет: provisioning делается с экрана Display
(`../clients/DISPLAY.md`, команды выше).

## 5. Разделение с Web

Web радио больше не владеет (раньше поднимал Wi-Fi сам). Теперь он поднимает только
HTTP+WS и стартует без IP — становится доступен, как только `wifi` получит адрес.
Так у радио один владелец, а у provisioning — один ответственный.

## 6. Реализация и статус

Компонент `wifi` (`wifi/src/wifi.c` — стек/скан/подключение/команды/автоподключение;
`wifi/src/wifi_select.c` — чистая логика выбора, покрыта host-тестом). Код компилируется
в прошивке; **на железе не проверено** (нет платы): подъём радио, скан, connect и
автоподключение ждут P4.
